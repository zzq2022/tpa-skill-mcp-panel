# 投研质检协议与门禁清单 (Review Checklist)

本文档是 Charles 投研框架在全生命周期各阶段（Phase 2 ~ Phase 8）的**刚性质量门禁标准**。各步骤执行必须严格对照自查，并在 Phase 8 生成终审报告。

---

## 1. Phase 2 (Editorial Planning) 规划内联自查清单

在生成 `plan/plan.md` 后，主 Agent **就地内联核查**（**禁止开 SubAgent，禁止写 review 文件**）：

- [ ] **标的格式**：标的代码是否包含标准市场后缀（如 `600519.SH` / `0728.HK`）。
- [ ] **周期明确**：分析周期与报告期是否精确到年份/季度（如 `2024FY`, `2025Q3`），无模糊描述。
- [ ] **对标池就绪**：同业对标池是否已配置 2~3 家可比同业或有合理的默认推荐。
- [ ] **结构四段合一**：规划文件是否完整包含 Brief / Scope / Outline / Artifacts 四段。

---

## 2. Phase 3 (Plan Checkpoint / Checkpoint 1) 人机决策硬门禁

- [ ] **硬阻断停下**：**必须停下**，严禁静默替用户选择，严禁以“默认执行”为由跳过答复。
- [ ] **5 项独立确认**：通过 `ask_question` 或编号消息向用户独立确认：
  1. 研究标的与证券代码
  2. 研究时间跨度 (Period Scope)
  3. 同业对标池 (Peer Group)
  4. 分析侧重点 (Research Focus)
  5. 交付格式 (Output Format)
- [ ] **准入铁律**：未获用户明确答复前，**严禁进入 Phase 4 开始取数**。

---

## 3. Phase 4 ~ Phase 7 中间步骤文件依赖与契约自查清单

各步骤执行后，主 Agent 验证下游前置依赖与门禁条件：

### Phase 4 (Step 1 信息差)
- [ ] **结构化数据**：`data/financial_data/` 下三大财务报表与财务摘要 CSV 已落盘且非空。
- [ ] **财报 PDF 原件**：`data/financial_reports/` 下对应财报 PDF 文件已成功下载。
- [ ] **解析与向量建库**：`data/parsed/` 解析文本就绪，`data/vector_db/index.faiss` 向量索引已成功构建。
- [ ] **RAG 证据挖掘**：必须运行 `query_report.py` 产出首轮 RAG evidence（包含实体页码 P.xx 与原文摘录）。
- [ ] **文本搜索限制**：文本搜索只能复核 RAG 返回的候选页，不能替代首次检索。
- [ ] **降级准则**：索引构建或 RAG 失败时记录 `retrieval_mode=direct-fallback`，Step 1 最多为 `partial`；无外部佐证时最多为 `partial`。
- [ ] **信封状态**：子 CLI 输出信封 `status` 为 `success` 或 `partial`（不可为 `failed`）。
- [ ] **严禁跳步**：**严禁仅依赖 CSV 而跳过财报 PDF 解析与向量检索**。

### Phase 5 (Step 2 逻辑差)
- [ ] **事实锚定**：成功读取 Phase 4 的客观事实与底层数据，推论均有前序事实锚定，无悬空假设。
- [ ] **因果链推导**：由 Agent 自主构建“事实 $\rightarrow$ 推断 $\rightarrow$ 假设”完整因果链，并落盘至 `analysis/logic_chain.md`。
- [ ] **回溯审计**：因果链的每个关键环节都能回溯到 evidence 或 analysis artifact。
- [ ] **逻辑差定位**：准确定位市场主流观点的过度线性外推、盲区或错误归因；缺少关键环节标为 `partial`。

### Phase 6 (Step 3 预期差)
- [ ] **量化指标与对标落盘**：`analysis/` 目录下财务比率、同业对标、行业供需或经营量化分析产物已生成。
- [ ] **可比参照基准确立 (Benchmark Anchor)**：已确立至少一种明确的客观参照基准：
  1. 机构一致预期（卖方 Consensus / 彭博 / Wind 预期）；
  2. 官方业绩指引 / 经营目标 (Management Guidance)；
  3. 行业/同业中位数基准 (Peer Median / Industry Benchmark)；
  4. 历史周期均值 / 估值中枢 (Historical Quartile)；
  5. 市场价格隐含预期 (Market Implied Pricing)。
- [ ] **预期差量化与持续性**：清晰对比“实际/预测事实”与“参照基准”，输出具体的偏离幅度（数值/百分比/拐点），并给出偏离是否具备持续性的逻辑支撑。
- [ ] **无基准降级**：若完全缺失任何可比基准（既无机构预期也无行业/历史对标），本步显式标注为 `unavailable` 并披露缺口，禁止使用“市场可能低估/高估”等无法量化的主观臆测代替预期差。

### Phase 7 (Step 4 催化剂与情绪)
- [ ] **舆情与事件落盘**：情绪/事件分析文件成功落盘至 `analysis/` 或 `data/news/`。
- [ ] **时间窗口锁定**：锁定能触发市场认知修正与重估的核心时间节点或催化窗口（如财报披露日、新产品发布、政策落地等），给出正反向触发条件。
- [ ] **泛叙事降级**：只有泛行业叙事而没有明确事件来源和时间窗口时，本步最多标为 `partial`。

---

## 4. Phase 8 (Step 5 终审交付) 三视角质检与数据源引用与可审计溯源清单

由独立 Reviewer SubAgent（或环境受限时由主 Agent 终审）执行，审查结果写入 `workspaces/<task_id>/review/final-review.md`：

### ① 数据与事实真实性 (Data Integrity & Citations)
- [ ] **正文脚注标记**：正文所有核心财务数据、派生比率与估值均具备标准 Markdown 脚注标记（如 `[^1]`、`[^2]`）。
- [ ] **专章审计清单**：研报正文末尾包含专门的《六、可审计数据源与证据清单 (Sources & Evidence Audit)》专章。
- [ ] **双向可点击穿透**：
  - 正文 `[^n]` 支持点击跳转至文末清单，文末包含 `↩` 反向返回锚点；
  - 本地源文件路径渲染为合规的 `file:///` 超链接，点击可直接呼出本地原始 CSV/JSON/PDF；
  - 外部政策/新闻链接渲染为可点击 URL。
- [ ] **计算合规性**：派生财务指标（ROE、周转率、派息率等）计算无明显异常值或口径颠倒。
- [ ] **数据诚信**：未披露或缺失的数据已如实标注为 `partial/unavailable`，严禁模型主观伪造数据。

### ② 逻辑闭环度 (Logic & Attribution)
- [ ] **因果链闭环**：逻辑差因果链闭环（事实 $\rightarrow$ 推断 $\rightarrow$ 假设）。
- [ ] **结论置信度对齐**：结论强度不得高于最弱的关键证据；证据链不支持时只能给中性/谨慎评级。
- [ ] **措辞严谨性**：没有目标价、历史估值分位或风险收益比时，**严禁使用“买点”“安全边际”“适合配置”等操作性措辞**。

### ③ 风险与失效条件 (Falsification & Risk)
- [ ] **证据状态表**：研报正文首部包含完整的《章节证据状态表》（含 `retrieval_mode` 与各步证据状态）。
- [ ] **核心假设失效条件**：正文中必须明确列出投资逻辑与估值重估的**具体失效条件 (Falsification Criteria)**（如关键财务指标跌破阈值即证伪）。
- [ ] **免责声明**：包含标准免责声明：“仅供研究参考，不构成投资建议”。
- [ ] **双产物交付**：`output/reports/` 目录下同时生成可点击 Markdown (`.md`) 与带悬浮气泡预览 (Tooltip) 的交互式 HTML (`.html`) 报告。
