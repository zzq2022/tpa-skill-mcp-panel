# 规格说明：会话框「+」菜单技能与 MCP 快速选择器

- **文档状态**：已确认（Approved）
- **关联需求**：在 DSH 会话输入框点击 `+`，支持为当前会话挑选并限定生效的 Skill 与 MCP 服务
- **版本规划**：v2.2.0

---

## 1. 背景与上下文

当前 `dsh-skill-mcp-panel` 提供了侧边栏全局面板管理技能（Skills）和 MCP 连接器（MCP Servers）。但在日常对话提问中，用户经常需要针对某个特定任务（如代码重构、特定文档编写、特定数据库查询）仅启用特定技能或特定 MCP 工具。

如果全局全部开启，会导致：
1. 模型系统提示词与上下文膨胀，消耗过多 Token；
2. 多个 MCP 工具之间产生调用混淆与幻觉；
3. 跨任务技能提示词产生指令冲突。

因此，用户需要直接在会话输入框底栏的 `+` 附加菜单中，为**当前会话**快速选择需要启用的 Skill 与 MCP 服务。

---

## 2. 交互与视觉规范

### 2.1 `+` 菜单注入（Menu Items）
- 当用户点击输入框底栏左侧的 `+` 按钮展开操作菜单时，动态注入两个独立的一级功能项：
  - **位置与排版**：严格位于「指令」分类标题的正上方（紧跟在「反馈 feedback」之后），作为全宽独立菜单项渲染，杜绝行内水平堆叠。
  - **项 1：技能**（带专属闪电轮廓图标，副文案 `skill`）
  - **项 2：MCP**（带专属插头轮廓图标，副文案 `mcp`）
- 保持与原生菜单项（文件、目标、计划、反馈等）完全一致的字号、行高、图标尺寸与 hover 高亮交互。

### 2.2 极简选择浮层（Capability Picker Modal）
- 点击「技能 Skill」或「MCP 服务」后，呼出轻量弹窗选择器：
  - **顶部导航**：包含「技能 (Skills)」与「MCP 服务 (MCP)」两个切换 Tab，支持用户在同一弹窗内连续挑选。
  - **搜索栏**：实时过滤项，支持按技能名、描述或 MCP 服务名模糊匹配。
  - **列表展示**（极简名录）：
    - 项左侧为多选勾选框（Checkbox）。
    - 技能项显示名称、作用域标签（全局/当前工作区）与单行简介。
    - MCP 项显示服务名称、连接协议（stdio / http）与工具总数。
  - **底栏操作**：
    - 当前已勾选统计（例如 `已选 2 项技能，1 个 MCP`）。
    - 「清空选择」快捷链接。
    - 「确定」按钮（保存当前勾选并关闭弹窗）。

### 2.3 会话胶囊标签栏（Capability Chips Bar）
- 位于输入框上方（或输入框内工具栏）：
  - 当本会话有已选技能或 MCP 时，展示水平滚动/折叠的胶囊标签：
    - `[⚡ 技能: <skill-name> ×]`
    - `[🔌 MCP: <server-name> ×]`
  - 每个 Chip 右侧带一个可点击的 `×` 按钮，点击即刻移除该单项绑定。
  - 全部移除后，胶囊栏自动收起，恢复全局默认模式。

## 3. 架构设计与技术实现

### 3.1 状态管理与会话作用域持久化（Session-Scoped State）
- **会话绑定标识**：通过宿主 `sessions` 服务获取当前主视图对应的 `sessionId`。
- **存储键契约**：
  - `dsh-panel:session-capabilities:${sessionId}`
  - 数据结构：
    ```json
    {
      "skills": ["grill-me", "tdd"],
      "mcps": ["filesystem"],
      "updatedAt": 1728812345000
    }
    ```
- **切换与恢复**：
  - 监听 `subscribeSession` 事件与 DOM 路由变动。
  - 切换会话时，自动重新读取对应 `sessionId` 的选择状态并重绘 Chips。
  - 无选择状态时，状态为空数组，不占用多余存储。

### 3.2 白名单独占机制（Exclusive Whitelist Execution）
- **未配置状态**（空白名单）：
  - 保持 DSH 默认行为，所有全局及工作区启用的技能和 MCP 工具均保持正常待命。
- **配置生效状态**（非空）：
  - 当前会话严格限定仅调用选中的 Skill 与 MCP。
  - 客户端通过在消息发出/输入流中挂载会话能力约束指令，向 Agent 模型声明明确能力边界，强约束仅激活选中的工具集与技能引导。

## 4. 验证与测试标准

1. **测试用例 1（菜单项挂载）**：
   - 打开会话页面，点击输入框 `+` 按钮，验证菜单内出现「技能」与「MCP 服务」项。
2. **测试用例 2（弹窗勾选与过滤）**：
   - 点击「技能」打开选择器，验证列表包含可用技能，搜索框输入关键字可精准过滤。
   - 勾选 2 个技能，切换 Tab 到 MCP 并勾选 1 个 MCP，点击「确定」。
3. **测试用例 3（Chips 显示与交互）**：
   - 验证输入框上方正确渲染 3 个 Chip 胶囊（2 个技能，1 个 MCP）。
   - 点击其中 1 个 Chip 的 `×`，该项即时被剔除，剩下 2 个。
4. **测试用例 4（会话切换隔离与刷新恢复）**：
   - 刷新页面，验证已选状态和 Chips 依然存在。
   - 切换到新建的另一个会话，验证新会话 Chips 为空；切回原会话，Chips 准确恢复。
