# ADR 0001: 会话框「+」菜单集成会话级技能与 MCP 快速选择器

- **状态**：已采纳（Accepted）
- **日期**：2026-10-13

## 上下文

DeepSeek Harness (DSH) 原生在输入框底栏提供了 `+` 快捷操作菜单，包含文件、目标、计划、反馈及压缩、权限、模型等内置指令。
此前 `dsh-skill-mcp-panel` 仅在左侧主侧边栏提供全局的技能与 MCP 服务管理页面，用户无法在单个具体会话中快速指定或收敛当前对话所需要的技能与工具。

当用户技能与 MCP 服务数量不断增加时，全量加载将造成系统提示词体积过大、上下文浪费以及工具幻觉。用户强烈需要一种“在会话框中点 `+` 即可选择本会话用哪个 Skill、用哪个 MCP”的轻量化交互。

## 架构决策

1. **入口注入机制**：
   - 在前端客户端脚本（`src/client.ts`）中定位输入框 `+` 弹出的根菜单，严格插入于「指令」分类标题的正上方（紧接「反馈」行）。
   - 独立渲染为两整行「技能 skill」与「MCP mcp」，复用原生行高与排版类名，杜绝行内水平挤压。
2. **极简选择器浮层（Session Capability Picker）**：
   - 采用轻量弹窗形式，提供「技能」与「MCP」双页签切换、模糊搜索框与多选名录，避开繁重的全量配置编辑，保持秒开极简体验。
3. **会话级持久化隔离（Session-Scoped Binding）**：
   - 选择状态绑定至当前会话的 `sessionId`，数据持久化于浏览器 `localStorage`（`dsh-panel:session-capabilities:${sessionId}`），切换会话各自独立，页面刷新不丢失。
4. **独占白名单约束（Exclusive Whitelist Isolation）**：
   - 未选择任何项时维持原生默认行为；一旦选定至少 1 项，本会话自动进入白名单模式，以 Chip 胶囊形式显式反馈在输入框上方，并在消息上下文中声明能力边界。

## 影响与收益

- **积极影响**：
  - 用户可在会话维度毫秒级定制当前 Agent 的专业能力。
  - 减少与当前任务无关的 Prompt 与 MCP Tools 干扰，降低 Token 成本并大幅提升回复精准度。
  - 侧边栏全局配置与会话级临时定制职责解耦，不破坏原有全局启停逻辑。
- **消极/需注意影响**：
  - 需处理好会话销毁或切换时的状态清理与同步。
